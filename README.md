# 🛒 Amazon Clone

## 📌 About the Project

This project is a front-end Amazon-inspired e-commerce website built using HTML, CSS, and JavaScript. It was created to practice web development fundamentals and build an interactive shopping interface without using any frameworks.

## 🌐 Live Demo

**[View Amazon Clone](https://saman-khan408.github.io/javascript-amazon-project-main/)**

## ✨ Features

* 🛍️ Amazon-inspired shopping interface
* 🎨 Product-focused layout and styling
* 📱 Responsive design (if implemented)
* ⚡ Interactive functionality using JavaScript
* 💻 Structured web pages using HTML and CSS

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Interactive functionality

## 📚 What I Learned

* Writing semantic HTML
* Styling web pages with CSS
* Using JavaScript to add interactivity
* Handling DOM elements and events
* Organizing front-end project files
* Building a website without JavaScript frameworks

## 🎯 Project Purpose

The goal of this project was to strengthen my HTML, CSS, and JavaScript skills by building an e-commerce-style interface inspired by Amazon.
